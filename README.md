
# Test Automation Framework

A modular test automation framework using Selenium WebDriver, TestNG, and Cucumber BDD for web application testing.

## Features
- Selenium WebDriver 4.16.1 integration
- Cucumber BDD implementation
- TestNG for parallel test execution
- Page Object Model design pattern
- Multi-browser support (Chrome, Firefox, Edge)
- Selenium Grid support via Docker
- Configurable test environments
- Screenshot capture on test failure
- HTML test reports

## Prerequisites
- Java 17 JDK
- Maven
- Docker (for Selenium Grid)
- Chrome/Firefox/Edge browsers
